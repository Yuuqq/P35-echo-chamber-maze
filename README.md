## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅳ 反思篇 · 第15章 媒介素养与受众分析**（教材 Tier 2 实验工具）。教材命名："信息茧房收敛模拟器"。

**学习目标**：通过连续点选同类立场观察信息流收敛与多样性指数衰减的过程，能够解释信息茧房的生成机制及其对受众认知的影响。

**核心术语**：信息茧房（Information Cocoon）、过滤气泡（Filter Bubble）、算法推荐（Algorithmic Recommendation）

**适合对象**：新闻传播专业学生 / 媒介素养学习者

**课前准备**：打开即用、离线可用；无账号体系、进度不自动保存，建议边玩边记录每轮的多样性指数。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师先展示初始多元信息流（A 支持/B 质疑/C 中立核查三类内容并存），随后连续点选 4 次"观点 A"，让学生观察信息流如何被 A 类内容填满、多样性指数从 100 一路跌入红色区间，并齐读四级警示文案的变化。
2. **上手实操**（20 分钟）：学生各自选择一个立场连续点击至少 8 轮 → 每轮记录多样性指数数值与信息流中异见条数 → 点"重置"恢复多元信息流，再换一个立场重复一轮 → 对照历史记录比较两轮的收敛速度 → 用一句话写出"第几轮开始我几乎看不到不同声音"。
3. **小组讨论**（8 分钟）：把你看过的信息流换成立场完全相反的用户，他看到的世界与你有何不同？打破茧房的责任主要在平台算法、媒体，还是用户自己？
4. **总结**（4 分钟）：茧房不是一次点击形成的，而是"每次相似选择都被放大一点"的累积结果——多样性指数就是这种累积的量化警报。

**课后作业**：完成一份"8 轮收敛实验记录表"（每轮指数＋异见条数），并用 300 字说明现实推荐算法与本工具模拟的相似与差异（各至少两点）。

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%
